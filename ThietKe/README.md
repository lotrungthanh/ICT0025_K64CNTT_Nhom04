## Yêu cầu môi trường

- Windows với XAMPP (Apache, PHP, MySQL/MariaDB) hoặc môi trường tương đương.
- PHP có extension `mysqli`.
- Database dùng tên `thuvien1`.

## Tạo và cấu hình cơ sở dữ liệu

1. Mở XAMPP, khởi động Apache và MySQL.
2. Mở phpMyAdmin tại `http://localhost/phpmyadmin`.
3. Tạo database tên `thuvien1`, chọn collation `utf8mb4_unicode_ci`.
4. Import tệp schema SQL do nhóm cung cấp/đang sử dụng vào database vừa tạo.
