# โปรเจกต์ส่วนของกลุ่มที่ 4: ระบบยืม-คืนห้องสมุด

## ไฟล์ที่รวม
- `muon_tra/` ระบบยืมหนังสือ, รายการยืม, คืนหนังสือ, ตรวจสอบค่าปรับ
- `bao_cao/` รายงานการยืมและคืน
- `config/db.php` การเชื่อมต่อ MySQL
- `assets/style.css` รูปแบบหน้าเว็บ

## ติดตั้ง
1. แตก ZIP ไปไว้ที่ `C:\xampp\htdocs\nhom4_thuvien`
2. เปิด XAMPP แล้ว Start Apache และ MySQL
3. ตรวจสอบว่ามีฐานข้อมูล `thu_vien1`
4. เปิด `config/db.php` ตรวจสอบ DB_USER/DB_PASS ให้ตรงกับเครื่อง
5. เปิดเว็บ `http://localhost/nhom4_thuvien/`

## ข้อควรทราบ
- โค้ดอิงจากคอลัมน์ที่เห็นในภาพของตาราง `phieu_muon` และ `chi_tiet_muon`
- ฟอร์มใช้การกรอกรหัส `ma_doc_gia`, `ma_nguoi_dung`, `ma_sach` โดยตรง เพราะยังไม่ได้เห็นโครงสร้างคอลัมน์ของตาราง `doc_gia`, `nguoi_dung`, `sach`
- ตัวอย่างคำนวณค่าปรับตั้งไว้ 1,000 VND/วันเพื่อเป็นค่าเริ่มต้นชั่วคราวเท่านั้น ต้องยืนยันอัตราจริงกับกลุ่มก่อนใช้
- ควรทดลองบนฐานข้อมูลสำเนาหรือข้อมูลทดสอบก่อน อย่าทดลองสร้าง/คืนรายการกับข้อมูลจริงโดยไม่ได้รับอนุญาตจากกลุ่ม
- หากชื่อฐานข้อมูลหรือรหัสผ่านต่างจากค่าที่กำหนด ให้แก้ใน `config/db.php`
